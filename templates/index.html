ℹ️ ABOUT PROJECT & VIVA VOCE PRESENTATION
Cyber Fraud Data Transaction Analysis and Detection System operates using a Random Forest Classifier trained on 100,000 transaction records. It preprocesses transaction features, handles missing values, engineers time-based domain attributes, and computes calibrated fraud probability. The system classifies risk into LOW (0-30%), MEDIUM (30-70%), and HIGH (70-100%) categories.
